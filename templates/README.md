# Adaptable templates

Copy only what the project needs, fill the fields, and remove template guidance from live assignments. Existing documents can serve these responsibilities. Do not install all templates as mandatory startup reading.

| Template | Suggested project destination |
|---|---|
| [AGENTS](AGENTS.md) | repository root |
| [CURRENT](CURRENT.md) | coordination/CURRENT.md |
| [WORKFLOW](WORKFLOW.md) | coordination/WORKFLOW.md |
| [TASK](TASK.md) | coordination/tasks/TASK-ID/TASK.md |
| [HANDBACK](HANDBACK.md) | same task folder, when implemented |
| [REVIEW](REVIEW.md) | same task folder, when reviewed |
| [OWNER-CHECKS](OWNER-CHECKS.md) | same task folder, when owner testing applies |
| [CONTEXT-MAP](CONTEXT-MAP.md) | docs/CONTEXT-MAP.md |
| [COMPONENT](COMPONENT.md) | docs/components/component-name.md |
| [PHASE](PHASE.md) | docs/phases/phase-or-milestone.md, if useful |

History and substantial decision records should be linked when created; avoid empty scaffolding for hypothetical future work. See the [playbook](../PLAYBOOK.md) for lifecycle rules.
